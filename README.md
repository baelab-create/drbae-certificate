# 닥터배 수료증 발급 시스템

기존 `26년_수료증_인쇄용 파일.pptx` 작업을 대체하는 웹 인쇄 프로그램입니다.
배경이 인쇄된 A4 가로 수료증 용지 위에 **글자만** 얹어 인쇄합니다.

## 파일 구성

- `index.html` — 앱 전체. 빌드·서버 불필요.
- `certificate-bg.png` — 수료증 배경 디자인 (A4 가로 297 × 210 mm).
  PPT 슬라이드 1의 `image1.png`(세로 1168 × 1644, `rot="16200000"` = 270° 회전)을
  가로로 돌려 저장한 것. 슬라이드 배치가 295.5 × 210 mm 가운데 정렬이라
  297 × 210 캔버스에 그대로 앉혔습니다.

## 좌표의 출처

원본 PPT(슬라이드 크기 297 × 210 mm = A4 가로)에서 147장 전부 동일하게 쓰이던
텍스트 상자 위치를 그대로 추출해 넣었습니다. PowerPoint 텍스트 상자 내부 여백
(lIns 2.54 mm / tIns 1.27 mm)까지 반영한 값입니다.

| 항목 | 위치 | 크기 | 서체 |
|---|---|---|---|
| 샵 이름 | 중심 X 83.83 mm, Y 96.80 mm | 28 pt, 밑줄 | Vladimir Script → 한글은 맑은 고딕 대체 |
| 원장/대표 이름 | 중심 X 83.83 mm, Y 109.96 mm | 11 pt | G마켓 산스 TTF Light |
| Dr. Bae Won-Gyu | X 182.25 mm, Y 96.70 mm | 28 pt, 밑줄 | Vladimir Script |
| 의공학 박사: 배원규 교수 | X 190.88 mm, Y 109.96 mm | 11 pt | G마켓 산스 TTF Light |
| Date 2026.08.13 | X 187.07 mm, Y 167.56 mm | 20 pt | Vladimir Script |

서체는 **PC에 설치된 폰트를 먼저 사용**합니다(PPT와 동일한 결과).
`Vladimir Script`, `G마켓 산스 TTF Light`가 없는 PC에서는 웹폰트로 대체 렌더링됩니다.

## 초기 데이터

원본 PPT에서 추출한 과거 수료자 **113명**이 명단에 미리 들어 있습니다.
(2023.08.09 ~ 2026.08.18)

## 용지 모드

| 모드 | 인쇄되는 것 | 쓰는 때 |
|---|---|---|
| 수료증 용지에 인쇄 (기본) | **글자만** | 배경이 인쇄된 수료증 용지를 쓸 때 |
| 일반 A4에 전체 인쇄 | 배경 디자인 + 글자 | 용지가 떨어졌을 때 일반 A4에 급히 |

화면 미리보기에는 두 모드 모두 배경이 보입니다. 위치를 눈으로 맞추기 위한 것이고,
`수료증 용지에 인쇄` 모드에서는 인쇄 시 배경이 빠집니다.

## 알려진 주의점 — 날짜와 밀랍 인장

PPT 원본 좌표 그대로 두면 `Date 2026.08.13` 의 오른쪽 끝이 **229.4 mm**,
밀랍 인장의 왼쪽 끝이 **약 224 mm** 라 5 mm 정도 겹칩니다.
`설정 → 날짜만 X` 를 **−8** 로 두면 끝이 221.4 mm 가 되어 2.6 mm 여유로 비켜갑니다.
기본값은 PPT와 동일하게 0으로 두었으니, 시험 인쇄 후 실제 용지를 보고 정하세요.

## 인쇄 방법

1. **발급하기** 탭에서 일자·샵 이름·원장 이름 입력
2. `저장 후 인쇄` → 브라우저 인쇄 대화상자
3. 인쇄 설정에서 반드시 확인:
   - **용지: A4 / 방향: 가로**
   - **여백: 없음**
   - **배율: 100 % (페이지에 맞춤 끄기)**
   - **배경 그래픽: 켜기** (`일반 A4에 전체 인쇄` 모드일 때만 필요)

첫 출력 전에 **일반 A4 용지에 시험 인쇄** → 수료증 용지에 겹쳐 보고,
어긋난 만큼 `설정 → 인쇄 위치 미세 조정`에서 mm 단위로 보정하세요. 보정값은 저장됩니다.

## 명단 탭

- 일자별로 묶여서 정렬 (최신순)
- 검색 / 기간 필터 / 발급·기록만 필터
- **+ 직접 추가** — 수료증을 주지 않은 사람도 명단에만 기록
- **선택 인쇄** — 체크한 여러 명을 한 번에 연속 인쇄
- CSV 내보내기 / JSON 백업·복원

## 데이터 저장 — 기기 간 공유

명단의 원본은 **Firebase Firestore `certs` 컬렉션**(프로젝트 `baelab-ledger`)입니다.
거래처 마스터·관리대장·발송 명세서와 같은 프로젝트라, 발급하면 대시보드·명세서에도 곧바로 반영됩니다.

| | 필요한 것 | 결과 |
|---|---|---|
| **읽기·쓰기** | 본사 Google 계정(baewongyu@gmail.com) 로그인 | 발급·수정·삭제가 모든 기기에 즉시 반영됩니다 |
| 로그인 전 | 없음 | 발급은 그 브라우저에만 임시 저장되고, 로그인하면 자동으로 올라갑니다 |

Firestore 보안 규칙상 `certs` 는 본사 계정만 읽고 쓸 수 있습니다(파트너 링크·공개 접근 불가).
팝업이 막히는 브라우저는 설정 탭의 리디렉션 로그인 버튼을 쓰세요.

### 동작 방식

- 접속 시 이 브라우저의 사본을 먼저 그리고, 로그인되어 있으면 `certs` 를 받아 병합합니다.
- 발급·수정·삭제 후 약 1.2초 뒤 자동 저장됩니다 (연속 작업은 한 번으로 묶임).
- 삭제한 항목은 묘비로 기록해 병합 때 되살아나지 않게 합니다.
- 헤더의 상태 칩을 누르면 즉시 동기화합니다.

저장소의 `records.json` 은 2026-09-13 Firebase 이전 전의 **옛 원본을 남겨 둔 과거 사본**입니다
(옛 포장 PC 코드 폴백용). 이 앱은 더 이상 읽지도 쓰지도 않으며, 이후 발급분은 들어 있지 않습니다.
저장소가 공개라 URL 을 아는 사람은 볼 수 있다는 점에 유의하세요. 예전 GitHub 토큰 등록 방식은 폐지되었습니다.
