기기 간 동기화

명단은 저장소의 records.json 한 파일에 저장됩니다. 읽기는 토큰 없이 어느 기기에서든 되고, 새 발급을 저장하려면 이 기기에 개인 토큰을 한 번 등록해야 합니다.

확인 중…
토큰 만들기 → Repository access 는 drbae-certificate 만, Permissions 는 Contents: Read and write 하나만 주세요. 입력한 토큰은 이 브라우저에만 저장되고 어디에도 전송되지 않습니다.
기록 원본: records.json · 발급할 때마다 커밋되어 변경 이력이 그대로 남습니다.

인쇄 위치 미세 조정

실제 수료증 용지에 시험 인쇄한 뒤, 글자가 밀린 만큼 mm 단위로 보정하세요. (+X = 오른쪽, +Y = 아래)

PPT 원본 위치 그대로면 Date 2026.08.13 의 끝이 밀랍 인장과 약 5mm 겹칩니다. 기본 디자인 용지를 쓰신다면 날짜만 X 를 −8 정도로 두시면 깔끔하게 비켜갑니다.

용지 / 배경

배경이 인쇄된 수료증 용지를 쓰실 때는 글자만, 용지가 떨어졌을 때 일반 A4에 급히 뽑으려면 전체 인쇄를 고르세요. 화면 미리보기에는 어느 쪽이든 배경이 보입니다.

기본 배경은 PPT 1페이지의 SF-MicroJection 디자인입니다. 다른 디자인 용지를 쓰신다면 스캔·촬영해 올려서 교체하세요.
